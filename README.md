# car-care-list

> 발행: **에이스종합관리(주)**

법인차량 운행기록 및 정비/관리 체크리스트 웹앱입니다.

## 기능

- 사용자 선택 로그인, 차량(레이/셀토스/스포티지) 선택
- 계기판 사진 촬영 → AI OCR로 주행거리(km) 자동 인식
- 운행기록 저장 및 관리자 화면에서 조회·필터·엑셀 내보내기
- 🔧 차량별 정비/관리 체크리스트(엔진오일·타이어·배터리·브레이크·냉각수·정기검사) 기록
- Firebase(Firestore)로 데이터 동기화

## 사용 방법

`index.html`을 GitHub Pages로 배포하거나 브라우저에서 직접 열어 사용합니다.

저장소 설정(Settings → Pages)에서 배포 브랜치를 지정하면
`https://airrotc29.github.io/car-care-list/` 에서 바로 접속할 수 있습니다.
